# Визуализатор алгоритмов поиска пути

Учебный проект — визуализация и сравнение трёх алгоритмов поиска
кратчайшего пути на сетке: **BFS**, **Дейкстра** и **A\***.

## Возможности

- Создание карты произвольного размера и загрузка/сохранение карты в JSON
- Установка старта и финиша, автоматическая и ручная расстановка стен
- Пошаговая и автоматическая визуализация работы выбранного алгоритма
- Сравнение всех трёх алгоритмов на одной карте (длина пути, число
  посещённых клеток)

## Архитектура

Проект разделён на независимые слои:

- `core/` — доменные модели (`Grid`) и абстракции (`PathFinder`,
  `MapRepository`), не зависящие ни от UI, ни от конкретных алгоритмов
  или способа хранения (принцип инверсии зависимостей).
- `algorithms/` — реализации `PathFinder` (BFS, Дейкстра, A*) и фабрика
  алгоритмов (`algorithm_factory.py`), позволяющая получать алгоритм
  по имени (паттерн **Strategy** + **Factory**).
- `storage/` — реализация `MapRepository` поверх JSON-файлов (паттерн
  **Repository**).
- `ui/` — интерфейс на tkinter: главное меню и рабочая область.
- `tests/` — модульные тесты для моделей, алгоритмов и хранилища.

## Запуск

```bash
python3 main.py
```

Требуется только стандартная библиотека Python 3.10+.

## Тесты

```bash
python3 -m unittest discover tests -v
```
